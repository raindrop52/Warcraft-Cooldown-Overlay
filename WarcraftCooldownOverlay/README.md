# Warcraft III Cooldown Overlay

Warcraft III 프로즌 쓰론의 창을 찾아 지정된 인벤토리 6칸과 스킬 7칸을 실시간으로 복제해 보여주는 Windows 오버레이입니다. 메인 설정 창에서 슬롯을 On/Off한 뒤 별도 오버레이를 실행합니다.

## 현재 슬롯 프로필

- 인벤토리: 2열 × 3행, 총 6칸
- 스킬: 둘째 줄의 오른쪽 3칸(빨간 원형 화살표 제외)
- 스킬: 셋째 줄 전체 4칸

사용자가 제공한 1920×1112 창모드 화면을 기준으로 상대 좌표를 사용합니다. Warcraft III 창의 위치가 바뀌어도 따라가며, 창 크기가 달라지면 캡처 좌표도 비례 조정됩니다.

## 실행

```powershell
dotnet run --project .\WarcraftCooldownOverlay\WarcraftCooldownOverlay.csproj
```

- 설정 창에서 각 아이템과 스킬의 실시간 미리보기를 확인할 수 있습니다.
- 체크박스로 필요한 슬롯만 On/Off할 수 있습니다.
- `오버레이 실행`을 누르면 선택된 아이콘만 표시됩니다.
- 가로/세로 배치를 선택할 수 있으며, 오버레이를 마우스로 끌어 이동할 수 있습니다.
- `F7`: 오버레이 실행/종료 전환
- `F8`: 프로그램 전체 종료
- 오버레이 실행 중에는 설정 창이 숨겨지고, 오버레이를 종료하면 자동으로 다시 표시됩니다.
- 선택한 슬롯, 배치 방향, 설정 창 위치와 오버레이 위치는 자동 저장되며 다음 실행 때 복원됩니다.
- 흰색 쿨타임 숫자가 감지된 슬롯은 빨간 테두리와 `CD` 배지로 표시됩니다.
- 이 커스텀 맵에서 사용하는 아이템 우하단의 작은 숫자도 쿨타임으로 판정합니다.

게임의 창 크기나 커스텀 UI가 달라 슬롯이 어긋나면 `MainWindow.xaml.cs`의 `Slots` 상대 좌표를 조정해야 합니다.
